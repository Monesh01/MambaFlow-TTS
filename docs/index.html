Executive Abstract

Modern non-autoregressive text-to-speech models frequently adopt multiscale temporal pyramids (e.g., U-Net downsamplers pooling by 2×, 4×, and 8×) to circumvent the quadratic computational memory cost of self-attention. However, we mathematically and empirically demonstrate that multiscale temporal pooling induces severe comb-filtering and destructive phase cancellation in high-frequency spectral sub-bands.

MambaFlow-TTS introduces a radically cleaner design: by substituting self-attention with bidirectional Mamba-2 state space models (SSMs), our architecture sustains strict 1× temporal resolution across every integration step while maintaining linear $O(T)$ memory scaling. Across 3 acoustic domains—48 kHz Meta DACVAE continuous latents, 24 kHz BigVGAN 100-mel spectrograms, and 22.05 kHz HiFi-GAN 80-mel spectrograms—MambaFlow demonstrates pristine speech quality (NISQA MOS 4.62), near-zero phoneme error rates (PER 1.29%), and inference speeds reaching 43.6× Real-Time.

Scientific Insights

The Three Core Empirical Ablations

Systematic explorations resolving fundamental questions in continuous flow matching, state space sequence directionality, and temporal resolution preservation.

Ablation A: Continuous Latents

Temperature × CFG Scaling Grid

We explored a 10-point evaluation grid crossing sampling temperatures ($T \in \{0.667, 1.000\}$) and Classifier-Free Guidance scales ($\text{CFG} \in [1.0, 3.0]$) in continuous 128D DACVAE latent space. While unguided inference ($\text{CFG}=1.0$) suffers from phonetic wandering, high guidance ($\text{CFG}=3.0$) causes oversaturation and clipping.

Optimal Operating Point: $T=0.667, \text{CFG}=2.0$ yields peak NISQA MOS 4.62 and minimum WER 3.84%.
Ablation B: Sequence Directionality

Non-Causal BiMamba-2 vs Causal

Comparing bidirectional dual-channel Mamba-2 against causal unidirectional forward-only Mamba-2 in 80-mel space. While causal models achieve higher throughput (43.6× vs 21.6× RT), bidirectional phonetic context propagation reduces validation flow loss from 0.3917 to 0.3313 and improves STOI from 0.697 to 0.711.

Takeaway: Bidirectional future context is essential for expressive prosody; causal SSM is preferred for ultra-low-latency streaming.
Ablation C: Comb-Filtering Suppression

Native 1× Resolution vs UNet Pyramid

Standard TTS architectures downsample acoustic features by 2× and 4×. When upsampled via transposed convolutions, skip-connection phase mismatches generate periodic cancellation notches across high-frequency bands (6–12 kHz). MambaFlow-Sequential-Tetra maintains full 1× resolution throughout, completely eliminating comb-filtering.

Result: Zero flanging, 35.3× RT inference, and lowest raw mel MAE (0.743) among all mel decoders.
Implementation

Minimal Python Quickstart

Synthesize speech in under 5 lines of Python using our pretrained checkpoints.

Python (PyTorch + MambaFlow) 
import torch
from MambaFlow_BiDirectional_Latent_VAE.TTSDataModule import TTSMODEL
from MambaFlow_BiDirectional_Latent_VAE.generate_audio import setup_dacvae, decode_latent_to_audio

# 1. Load Flagship 448D Checkpoint (42.2M params)
model = TTSMODEL.load_from_checkpoint("Checkpoints/MambaFlow-CA-BiMamba-448D.ckpt", map_location="cuda").model.eval()
dacvae_decoder, _, _ = setup_dacvae(device="cpu")

# 2. Synthesize High-Fidelity 48 kHz Speech (Euler 30-steps, CFG=2.0)
text = "MambaFlow-TTS eliminates multiscale aliasing through full-resolution state space flow matching."
with torch.inference_mode():
    audio_48k = model.synthesize(text, n_timesteps=30, temperature=0.667, cfg_scale=2.0, dacvae=dacvae_decoder)

# audio_48k is ready: 48 kHz, pristine naturalness, zero flanging artifacts!
